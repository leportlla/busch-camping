# Busch Camping

Site estático (HTML + CSS), sem dependências nem etapa de build.

## Estrutura

```
busch-camping/
├── index.html        # conteúdo, uma <section> por assunto
├── css/styles.css    # tokens, base, componentes e seções, nessa ordem
└── images/           # fotos nomeadas pelo conteúdo
```

## Como usar

Abra `index.html` no navegador, ou envie a pasta inteira para qualquer hospedagem estática.

## Onde editar

- **Cores e modo escuro:** variáveis no início de `css/styles.css`.
- **Links de reserva:** botões em `#cabanas` (Airbnb e Booking) e em `#camping` e `#reservas`.
- **Fotos:** troque o arquivo em `images/` mantendo o nome, ou ajuste o `src` no HTML.
